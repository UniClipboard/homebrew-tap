# homebrew-uniclipboard

Homebrew tap for [UniClipboard](https://github.com/UniClipboard/UniClipboard) - privacy-first cross-device clipboard sync.

## Install CLI

```bash
brew tap UniClipboard/tap
brew install uniclipboard
```

## Install App

```bash
brew tap UniClipboard/tap
brew install --cask uniclipboard
```

## Upgrade

```bash
brew update
brew upgrade uniclipboard
brew upgrade --cask uniclipboard
```

## Uninstall

```bash
brew uninstall uniclipboard
brew uninstall --cask uniclipboard
brew untap UniClipboard/tap
```
